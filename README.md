# Luca Speaks

A picture talking board for Luca. He taps a picture and the app says it out loud: needs, feelings, rest, play, TV shows, family, and the signs for More and All done.

Open it on an iPad or phone, then use **Add to Home Screen** so it opens full screen like an app. Press and hold Grown-ups to change picture size, hide pictures, add your own photos, and see what he said today.
